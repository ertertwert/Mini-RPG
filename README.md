This is the first 'game' I've ever made. I built this as a learning tool to better acquaint myself with the workflow with using Fable 5.2.

You can drop your own music files into the game if you don't want to use mine and you can have up to 20 for each 'theme.' Just name them in order (battle1.mp3, battle2.mp3, battle3.mp3, etc).
It will dynamically look for them when loading up the game each time.
